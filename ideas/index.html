New Product Thinking

What should Docode build next?

FrameScore proves the pattern: find a real-world workflow still running on paper, memory and group chats, then make the table-side tool that respects how people actually play.

The next Docode product should stay focused, practical and launchable, but it should open a larger path than one app at one table.

Flagship Idea

ClubNight

A live command centre for local sports clubs.

ClubNight helps small clubs run the messy bit between people arriving and results being written down: check-ins, table queues, match boards, ladders, quick scores, player availability and session history.

It starts where FrameScore lives: amateur clubs, practice nights and local competitions. Instead of replacing club culture, it quietly organises the night so players spend less time asking who is next and more time playing.

Explore ClubNight See FrameScore

Why it has teeth

  • clubs already have the problem every week
  • the buyer is clear: club organisers and committees
  • it can start with snooker, pool and darts
  • it naturally connects to FrameScore match data
  • it can grow without becoming a bloated social network

ClubNight Concept

From club chaos to one calm board.

A typical club night can involve arrivals, late players, available tables, friendly games, league matches, handicaps, text messages, paper fixtures and someone trying to remember who won.

ClubNight would turn that into one shared board for the organiser and one simple view for players.

The wedge is not “another sports app”. The wedge is “make tonight run properly”.

First Version

  • player check-in for a club session
  • live table or board queue
  • quick match creation
  • simple score entry
  • club ladder and session results
  • organiser notes and no-show tracking
  • exportable results for committee records
  • FrameScore integration for snooker matches

Product Shape

Small enough to build, useful enough to spread.

ClubNight should begin as a club-night organiser for cue sports and darts, then expand only where the workflow repeats.

Session Board

A live list of who is here, who is waiting, who is playing and which table or board is free next.

Match Queue

Create fair rotations for practice nights, challenge ladders and friendly games without a clipboard.

Results Memory

Keep lightweight history for players and committees, including scores, attendance and streaks.

Club Modes

Start with snooker and pool, then adapt the same model to darts, table tennis, squash and chess nights.

Validation Plan

How to prove ClubNight is worth building

The first step is not a big platform. It is a tight test with real organisers who already run club nights by hand.

1

Interview organisers

Ask how they currently manage arrivals, queues, fixtures, substitutions, results and late players.

2

Prototype one night

Build a static clickable flow for check-in, queue management and result entry before writing app code.

3

Pilot with FrameScore

Run a snooker-focused pilot where FrameScore handles the match and ClubNight handles the room.

Business Model

A product clubs can justify

ClubNight should be affordable enough for small committees and useful enough that one organised person can champion it.

  • free tier for one organiser testing a small session
  • club subscription for shared boards, history and exports
  • sport-specific add-ons only when they solve a real workflow
  • no advertising feed, no tracking-heavy community layer

Other problems worth solving

FixturePilot

Next Build Candidate

ClubNight is the strongest follow-up.

It is close enough to FrameScore to reuse insight, but broad enough to become a product family for clubs that need practical tools, not another noisy feed.
