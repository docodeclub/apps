Before Contacting Support

  • check that iPadOS is up to date
  • restart FrameScore and try the action again
  • confirm whether the issue happens in a new match
  • note whether iCloud sync is enabled, if relevant
  • include screenshots if they help explain the issue

Details That Help

  • your iPad model
  • iPadOS version
  • FrameScore app version, if visible
  • a short description of the issue
  • steps to reproduce the problem, if relevant
  • whether the issue affects scoring, player profiles, match history, iCloud sync or app settings

App Store Review and Availability

FrameScore is currently in the App Store approval process. If you are reviewing the app for App Store Connect, this page provides the official support contact for Docode Limited.

If FrameScore is not yet available in your region or on the App Store, please check back after approval or contact support with any review-related questions.
