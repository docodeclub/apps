FrameScore Support

Help, bug reports, feature requests and privacy questions.

For support, bug reports, feature requests or privacy questions, contact:

support@docode.co.uk

We aim to respond as soon as practical. Clear details help us investigate and reproduce issues more quickly.

Please include

  • your iPad model
  • iPadOS version
  • a short description of the issue
  • steps to reproduce the problem, if relevant

Before Contacting Support

  • check that iPadOS is up to date
  • restart FrameScore and try the action again
  • confirm whether the issue happens in a new match
  • note whether iCloud sync is enabled, if relevant
